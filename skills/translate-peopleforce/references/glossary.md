# Glossary

One row per concept, one column per language — to translate between two languages,
read those two cells of the same row. Only terms that encode a house choice are
listed; ordinary vocabulary any translator gets right is deliberately absent. The
glossary is revised continuously — a listed term is the current house pick.

| Marker | Meaning |
|---|---|
| — | No established form. Never coin one silently: propose a rendering and record it in the handover's *Words I am not sure about*. |
| *(empty cell)* | Not yet examined for that language. Translate on your own judgement and list the term in *Words I am not sure about*. |
| `a (x) / b (y)` | Several established terms, **chosen by context**. The bracket is the trigger, not a gloss. |
| `a / b (y)` | **The unbracketed form is the default**; the bracketed one applies only while its trigger holds. |
| `a / b` | Several established terms, **interchangeable** — pick one and stay consistent within the piece. |
| `a (x) / —` | The bracketed trigger is the **only** licensed use; outside it the `—` rule applies. |
| `n/a` | The concept **does not exist in this market** — never render it; restructure or drop per the row's note. |

**The EN column** is normally the row's own key; it differs only where the key cannot
carry the English form (`assets (company property)` is written **`assets`**; `resume /
CV` holds both established terms). Casing is not recorded here — echo the source's.

**Polish and Ukrainian cells give the lexeme to choose, not a string to paste** — pick
the word, then inflect it for the slot it lands in.

## Names

**Personal names — the script follows the person.** In Ukrainian copy a Ukrainian
person is written in Cyrillic whatever script the source used, and the name and the
role title beside it inflect; anyone else keeps their own script — never invent a
transliteration. One answer for the whole piece. Spanish takes the source spelling.

**Company and brand names keep the Latin original, with their diacritics repaired**
(`Zabka` → `Żabka`) — inside Cyrillic copy too. A Ukrainian company with a Ukrainian
name follows the language of the copy: Cyrillic in Ukrainian copy (`Нова Пошта`),
Latin in Polish, Spanish and English (`Nova Post`).
